Temperature Explorer

The probabilities are the softmax (sigmoid in multi-label mode) of the class logits divided by the temperature T. The predicted class, the accuracy and the confusion matrix do not change with T: only the spread of the probabilities, so the thresholds move with it. With two classes the recall at a target precision stays the same; with more classes it can move a little.

To deploy a temperature, open this page with scripts/evaluation/serve_temperature_explorer.py, press Save Thresholds At This Temperature, then Export: the thresholds of every class at the temperature shown are written next to the evaluation as saved_temperature_thresholds.json, and the export builds that temperature into the classifier with these thresholds, in <run>/Exports/. A temperature can be saved and exported again at any time. Opened as a plain file, the button downloads the file instead, which vision_training/deployment/export_model.py reads with use_saved_temperature once placed next to the page.
