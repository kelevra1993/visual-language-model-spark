TRAINING

Stop any time, launch again to resume

  • Ctrl+C saves a checkpoint of the last step.
  • The same file resumes, optimizer state included.
  • Changed labels stop the resume.
  • Failing iterations are skipped; over 5 in a row stop the run.
The run name decides the folder, and the last checkpoint of that folder decides between a new run and a resume: weights, optimizer state and moving average of the weights are loaded and the training continues at the next iteration. number_iterations is the total of the run, not the iterations left. Settings without a run name token, such as the batch size or the learning rate, may change between resumptions; the changes are printed and the previous configuration is kept. A labels.json whose SHA-256 differs from the one recorded in data.json stops the resume, unless allow_data_change_on_resume is set. A failing iteration is reported in yellow and skipped, and more than 5 in a row stop the training, saving a checkpoint.
