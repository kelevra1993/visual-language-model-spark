GETTING STARTED

A first training in minutes, on synthetic shapes

  1. Install the locked environment with uv.
  2. Generate the synthetic dataset of the task.
  3. Point its configuration to it, then train.

uv sync
uv run python -m vision_training.data.\
synthetic.create_synthetic_dataset \
--task=<task> \
--output_folder=<dataset folder>
uv run python -m vision_training.main \
--configuration_path=<synthetic yaml>

Every task ships a synthetic dataset, so a configuration or an installation is checked without any real data.

Three commands from a fresh clone to a running training: the generator writes the dataset of the task it is given into the folder it is given, and the synthetic configuration of the task names that folder before the training. The synthetic generator covers every task: single shapes for classification, five or six shapes per image with their masks for detection and segmentation, stick figures and houses for keypoints, moving shapes for sequences.
