DEPLOYMENT

Every export is checked before it is served

  • Writes TorchScript and ONNX, each with its Triton configuration.
  • Checks every format against the PyTorch model.
  • Replaces the served models only once every format matches.
  • One served model name per task.
vision_training/deployment/export_model.py takes a run, an iteration and trained or averaged weights, and writes the model as TorchScript and ONNX, each with its Triton configuration. Everything is first written to a staging folder, and every format is compared with the PyTorch model on a batch of another size than the traced one, with the tolerances of the task. Only when every format matches are the served models replaced; otherwise the export stops and the served models are left as they were. Each task has one served model name, from image_classifier to frame_selector.
