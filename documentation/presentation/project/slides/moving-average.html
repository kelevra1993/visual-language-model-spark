Averaged weights scored at every evaluation

  • A second copy of the weights, averaged over about the last 1,000 iterations.
  • Both copies are scored at every evaluation.

Detection tutorial run, 2,000 iterations: test mAP 67.49 % averaged, 53.38 % trained.

Optimization.exponential_moving_average keeps a second copy of the weights, moved towards the trained ones after every optimizer step: at a decay of 0.999 it follows about the last 1,000 iterations, and a short run averages fewer because of the warm-up (left). Every test evaluation scores both copies, in the EMA Weights report and under Test_EMA in TensorBoard, and the export can take either. On the right, the two launches of stage 13 of the classification benchmark, scored with their trained and their averaged weights. In the detection tutorial run, a short run of 2,000 iterations on synthetic shapes, the averaged weights reach 67.49 % test mAP@[0.5:0.95] against 53.38 % for the trained ones. It adds no token to the run name, so it can be switched on or off when a run resumes.
