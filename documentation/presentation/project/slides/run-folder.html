TRAINING

Everything about a run lives in one folder

training_configuration.yaml settings of the last start

Results.txt report of every evaluated checkpoint

data.json class counts, SHA-256 of labels and images

Evaluation/ files of every test evaluation

Weights/ weights, optimizer state, averaged weights

Checkpoint_Evaluation/ evaluations run later

Tensorboard/ train, validation and test curves

mlflow_run.json its MLflow run, tracking on

Every training writes to experiment_folder/run name, so a run can be audited, resumed or compared from its folder alone. The timeline is the classification run of the README images: a console summary every 10 iterations, a checkpoint every 250 and a test evaluation every 500, each set by its own key. The folder keeps the configuration of the last start, data.json with the class counts and the SHA-256 of the labels and images of every split, the checkpoints with their optimizer state and moving average of the weights, the TensorBoard curves, Results.txt with the report of every evaluated checkpoint, Evaluation/ with the files of each evaluation, Checkpoint_Evaluation/ for evaluations run later with evaluate_checkpoint.py, and mlflow_run.json when MLflow tracking is on.
