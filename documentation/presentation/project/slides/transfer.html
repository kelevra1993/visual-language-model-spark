TRAINING

Start any component from another run

  • The backbone comes from a run of any task; heads, decoder and temporal module too.
  • Layer settings checked identical before the training.
  • A deeper source lends its first blocks; a head can grow to more classes.
  • Freeze it, or fine-tune it with a learning-rate multiplier.
To start from a trained component, for example a backbone trained on ImageNet for a detector, give its run in the pretrained block of the section. The backbone comes from any task; the temporal module, classification head, segmentation decoder, region proposal, detection heads, mask heads, and the high resolution network with its keypoint head move between runs of the tasks that have them. The settings defining the layers must be identical in both runs, checked before the training, while the image size may differ. A backbone can load the first blocks of a deeper source, such as the stem of a keypoint detector, and a component with class layers can initialise a run with more classes, the source classes first in the same order. The loaded part can be frozen or fine-tuned slower, 0.1 meaning ten times slower than the new layers, and the averaged weights of the source are loaded when both runs keep them.
