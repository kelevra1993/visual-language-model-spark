To start: the README, then documentation/, then the tutorial videos.

The serving benchmark of 17 November (three models, every export format, dynamic batching on and off, latency, throughput, memory and the test metric through every served format) leaves its follow-ups: serving defaults (TensorRT FP16, the exported dynamic batching off) and a faster batched NMS for the eager and TorchScript detectors. Two of its findings are fixed since: the exported NMS of the detectors no longer overflows FP16 (its TensorRT FP16 engine within 0.21 points of the eager model), and the ONNX export writes the output frames of the sequence labeller and frame selector dynamic, so that Triton loads them. It also decides on native TensorRT engines built at export and a mounted engine cache; INT8 and FP8 need calibration or quantization nodes first. The instance segmentation benchmark, run stage by stage like the detection one, ended on 27 November: the image branch of the mask heads (design A, tied with the U-Net skips of design B, 88.65 % against 88.59 % test mask mAP), the bilinear doublings and one mask head shared by the levels were kept (87.17 % test mask mAP at 10,000 iterations), the level chosen by box size, a finer map and mask scoring were dropped, and the winners are shipped in the 1024 pixel example configuration. Newcomers start with the README, then the reference and workflow documents, then the videos.
