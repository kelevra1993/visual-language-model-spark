To start: the README, then documentation/, then the tutorial videos.

The serving numbers so far were taken once on a shared GPU, so the first step is a proper benchmark on an idle GPU: three models (a classifier, the reference detector and a sequence labeller), every export format, dynamic batching on and off, measured with NVIDIA’s perf_analyzer for latency, throughput, memory and the test metric against FP32. That benchmark then decides on native TensorRT engines built at export, BF16 in the export settings and a mounted engine cache; INT8 and FP8 need calibration or quantization nodes first. In parallel, the instance segmentation benchmark continues stage by stage like the detection one: stages 0 to 2 are done with a reference test mask mAP of 78.84 %, next come the mask head size and the finer inputs of the mask heads, then upsampling, a shared mask head, the level chosen by box size, a finer map and mask scoring. Newcomers start with the README, then the reference and workflow documents, then the videos.
