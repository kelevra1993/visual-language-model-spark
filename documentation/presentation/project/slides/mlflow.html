EVALUATION

One sortable table of every training run

One setting records every training in MLflow.

  • Sort and filter all runs by any setting or metric.
  • Each run keeps its configuration, git commit, best iteration and test metrics.
  • It also notes whether the code had uncommitted changes.
Turning on ExperimentConfiguration.tracking.activated records each training in an MLflow database inside the experiment folder; “mlflow ui” then shows this table, here four classification runs sorted by test accuracy. Opening a run shows the last value of every metric and its tags: its folder, its transferred components, the git commit, whether the working tree held uncommitted changes, and the best iteration. A resumed training continues its MLflow run. The per-iteration curves stay in TensorBoard, and checkpoints and images are not sent to MLflow.
