GETTING STARTED

The run name is built from the settings

  • Same settings: the run resumes in its folder.
  • Changed settings: a new run folder.
  • A suffix gives the same settings a run of their own.

The name alone tells what a run trained.

vision_training/configuration_processing/run_name.py builds the run name from the configuration, section by section. Read the example from left to right: classification, input normalization, kept aspect ratio and a 256-pixel input, a backbone of six blocks with squeeze-and-excitation, residual shortcuts and batch normalization, initialised from another run (PT), a head with two hidden layers of 96, a multi-label output of 35 classes, and the suffix “counted-shapes”. The same settings resume in the same folder; any setting with a token gives another name, so a new folder, while the settings without a token (batch size, learning rate, augmentation, dropout, moving average of the weights) may change when a run resumes. The README gives example names for classification, detection and sequence classification, and the configuration reference one for every task.
