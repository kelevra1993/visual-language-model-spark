The console shows what changed and improved

  • At launch: run name, clickable folders, settings and data changed since the last start.
  • Every information_dump iterations: interval averages of both splits.
  • Green when better, Best when best of the run.

A run can be judged live, without opening TensorBoard.

So that a run can be followed live, the trainer prints at launch the run name, its folders as clickable links, the settings and data changed since the last start, the transferred components, the splits and the model summary. Every information_dump iterations it prints the averages of the interval for train and validation, each with its change since the previous summary, green when better, red when worse, and “Best” when it is the best of the run for its split. Rates are shown as percentages and their changes in points. Point at iteration 1410: validation accuracy up 6.87 points, marked Best.
