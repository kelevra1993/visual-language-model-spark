GETTING STARTED

Your data: one folder per split and a mapping

  • Train, validation and test folders: images in data/, labels in labels.json.
  • label_mapping.json maps categories to classes, merging or dropping some.
  • COCO format for detection, instance segmentation and keypoints.
  • Converters for class folders and pair lists.
Every task reads the same layout: a train, a validation and a test folder, each with its images in data/ and a labels.json manifest. label_mapping.json maps every category identifier of the manifests to the class the model predicts, so categories can be merged, or left out by not naming them, without touching the manifests. Detection, instance segmentation and keypoints use COCO, so existing COCO annotations load as they are; class_folder_manifests.py converts one folder per class for classification and pair_list_manifests.py converts pair lists for sequence comparison.
