GETTING STARTED

Your data: one folder per split and a mapping

  • Train, validation and test folders: images in data/, labels in labels.json.
  • label_mapping.json maps categories to classes, merging or dropping some.
  • COCO format for detection, instance segmentation and keypoints.

PLANNED, NOT DONE YET

label_mapping.json and labels.json merged into one file, simpler to prepare.

Every task reads the same layout: a train, a validation and a test folder, each with its images in data/ and a labels.json manifest. label_mapping.json maps every category identifier of the manifests to the class the model predicts, so categories can be merged, or left out by not naming them, without touching the manifests. Detection, instance segmentation and keypoints use COCO, so existing COCO annotations load as they are. Point at the right side of the figure: one image, its entry in labels.json, and the mapping that turns category 29, a hollow trapezoid, into class index 28. Planned, not done yet: label_mapping.json and labels.json will be merged into a single file, so that preparing a data set takes one label file instead of two; until then, both files are needed.
