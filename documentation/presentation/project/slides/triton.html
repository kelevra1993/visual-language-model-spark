DEPLOYMENT

Triton serves every model behind one endpoint

  • docker compose up serves every exported model.
  • HTTP 8000, gRPC 8001, metrics 8002.
  • Requests within 1 ms are batched together, up to 16.
  • Clients need only tritonclient and numpy.
One docker compose command, from vision_training/deployment/triton, starts NVIDIA Triton with every model of served_models: HTTP on port 8000, gRPC on 8001, Prometheus metrics on 8002. Each model has a dynamic batcher: requests that arrive within one millisecond of each other run as one batch, up to 16 images, which pays off when several cameras or services query the same model at once. The client prepares the photo as the input contract says and sends a tensor; it needs tritonclient and numpy, not PyTorch nor CUDA. The frame selector runs as an ensemble that chains its GPU network and its CPU decoder.
