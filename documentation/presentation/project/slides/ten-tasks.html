WHAT IT TRAINS

Ten tasks, from single images to sequences

CodeTaskInputOutput
CLSClassificationone imageone class, or several (multi-label)
DETObject detectionone imageboxes with their class and score
INSInstance segmentationone imageboxes and the mask of every object
KPTKeypoint detectionone imageobjects with their keypoints
SEGSemantic segmentationone imageone class per pixel
M2OSequence classificationa sequence of framesone class per sequence
M2MSequence labellinga sequence of framesone class per frame
CMPSequence comparisona before and an after sequenceone class per pair
SELFrame selectiona sequence of framesthe frames of every wanted class
SSLSelf-supervisedunlabelled imagesa pre-trained backbone for the others
Five image tasks, four sequence tasks (shaded), and self-supervised pre-training that initialises the backbone of the others without labels. Each task adds its own dataset, head, losses and metrics; everything else is shared.
