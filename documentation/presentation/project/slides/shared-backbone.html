ARCHITECTURE

Every task plugs its head onto one shared backbone

Shared means the same classic CNN design for every task, not the same weights: each task trains its own.

Convolution blocks with optional residual, squeeze-and-excitation and inception modules; pre-trained weights load into any task.

Shared refers to the design, not to the weights: every task starts from the same classic convolutional backbone, configured block by block, and trains its own parameters; two tasks never update one set of weights. Image tasks read one or several of its levels; sequence tasks run it on every frame and add a temporal module (GRU, LSTM, transformer, temporal convolution or pooling). Because the design is the same everywhere, weights trained on one task, on ImageNet or by self-supervision can initialise the backbone of any other through the transfer settings; without them, a task trains its backbone from scratch.
