ARCHITECTURE

Every task plugs its head onto one shared backbone

Convolution blocks with optional residual, squeeze-and-excitation and inception modules; a backbone pre-trained by SSL loads into any other task.

The backbone is configurable block by block. Image tasks read one or several of its levels; sequence tasks run it on every frame and add a temporal module (GRU, LSTM, transformer, temporal convolution or pooling). Because the backbone is shared, a backbone trained on one task, or on ImageNet, or by self-supervision, can initialise any other.
